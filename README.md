# Iceberg Económico de Argentina

Infografía mensual con los indicadores de la economía argentina —lo que se ve (inflación, pobreza, salarios, dólar) y lo que está debajo (reservas, actividad, crédito y más)—, por @elprofeagop y KARTAL Consulting.

- **Se ve en:** https://kartal.com.ar/iceberg
- **Se actualiza sola una vez por mes:** cada edición nueva reemplaza `index.html` e `iceberg.png` en este repo y GitHub Pages la publica.
- **Sin datos privados:** el repo solo contiene la página pública y la imagen; no lleva claves, credenciales ni datos personales.
